# Random Die-Cut Generator v2

업로드한 이미지에 랜덤 펀칭을 만들고, 잘려 나온 조각을 아래에 흩뿌려 PNG로 저장하는 브라우저 전용 도구입니다.

## v2 변경점

- 사용자 정의 PNG 마스크 추가
- 가로 최소 / 최대 크기 조절
- 세로 최소 / 최대 크기 조절
- 비율 유지 옵션 추가
- 기본 도형의 불필요한 랜덤 찌그러짐 제거
- 사용자 PNG는 원본 PNG의 알파(투명도)를 마스크로 사용

## GitHub에서 기존 버전 교체하기

저장소 최상위의 기존 `index.html`, `style.css`, `script.js`, `README.md`를 이 압축파일의 새 파일로 교체한 뒤 Commit changes 하면 됩니다.

GitHub Pages는 같은 저장소를 계속 사용하므로 별도의 Pages 설정은 다시 할 필요가 없습니다.


## v3 수정

- 사용자 PNG의 **색상(RGB)은 완전히 무시**하고 투명도(알파)만 마스크로 사용
- `펀칭 테두리`를 켜도 마스크 PNG 자체의 색이 나타나지 않도록 수정
- 사진 쪽 펀칭은 선택한 `펀칭 배경` 색으로 표시
- 아래 조각은 원본 사진 픽셀만 마스크 모양으로 잘려 표시


## v4 변경점

- 하단 종이 영역을 원본 이미지와 정확히 같은 크기로 고정
- 하단 조각 배치 방식 추가:
  - 랜덤
  - 원본 펀칭 위치와 동일
  - 가운데 정렬
- 슬라이더 우측에 직접 숫자를 입력할 수 있는 입력칸 추가
- ‘흩뿌림 높이’는 하단 종이 크기를 바꾸지 않고, 랜덤 배치 시 조각이 퍼지는 세로 범위만 조절
