# Random Die-Cut Generator

브라우저에서 이미지를 업로드해 랜덤 펀칭 효과를 만들고, 잘려 나온 조각을 아래 종이 영역에 배치해 PNG로 저장하는 웹 도구입니다.

## 주요 기능

- 기본 펀칭 모양: 물방울, 원, 마름모, 별
- 사용자 정의 PNG 마스크 지원
- 사용자 PNG의 투명도(알파)만 모양으로 사용
- 조각 개수 조절
- 가로/세로 최소·최대 크기 조절
- 비율 유지 옵션
- 회전 랜덤 조절
- 펀칭 테두리 표시 여부 선택
- 펀칭 배경: 종이색 / 흰색 / 투명
- 하단 종이 영역은 원본 이미지와 동일한 크기
- 하단 조각 배치 방식:
  - 랜덤
  - 원본 펀칭 위치와 동일
  - 가운데 정렬
- 가운데 정렬은 조각 개수에 따라 최대한 정방형에 가까운 그리드로 배치
  - 예: 30개 → 6×5
- 슬라이더와 숫자 직접 입력 모두 지원
- PNG 저장
- 모든 이미지 처리는 브라우저 안에서만 수행

## 사용 방법

1. 원본 이미지를 업로드합니다.
2. 펀칭 모양을 선택합니다.
3. 사용자 PNG를 사용할 경우 투명 배경 PNG를 추가합니다.
4. 조각 개수와 크기, 배치 방식을 조절합니다.
5. 필요하면 다시 랜덤으로 생성합니다.
6. PNG 저장 버튼으로 결과를 저장합니다.

## Privacy

업로드한 이미지는 외부 서버로 전송되지 않으며 브라우저 내부에서만 처리됩니다.
